# App

Flutter 3, un solo código para Android, iOS y web. El mapa usa `flutter_map` y teselas de OpenStreetMap.

```bash
flutter run -d web-server --web-port 8080 --dart-define=API_BASE=http://localhost:8001
```

La API tiene que estar en marcha. Quien no tiene cuenta puede ver el mapa; para dejar una historia hay que entrar. El punto de la historia es el centro del mapa en el momento de abrir el formulario.
